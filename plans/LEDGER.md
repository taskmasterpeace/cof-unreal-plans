## Rules for this file

- **Status words:** OPEN · IN PROGRESS (seat, date and time) · PARTIAL (what is left) · BLOCKED (by what) · DONE (date; proof required).
- **Claiming a job:** before any work, change its status to `IN PROGRESS <seat> <date time>` and commit that one line by
  itself. If the commit shows someone else claimed it first, take another job. A claim older than 24 hours with no
  commits behind it is dead and may be taken.
- **One writer in this folder.** A second session works in its own copy: `git worktree add ..\cof-unreal-lane2 -b lane2`
  from this repo, and merges back when its job is DONE. Sub-agents of one session count as that session.
- **Needs** lists jobs that must be DONE first. **Unreal** says if the editor must be open. Run
  `powershell tools\unreal-busy.ps1` first; if it prints BUSY, take a job marked "no".
- **Proof** is a short text file in `docs/proof/` (versioned): the command run, its output, the numbers. Clips and
  pictures stay in `tools/proof/` (local only) and the text file names them.
- **SPLIT FIRST** rows are too big for 24 hours. The session that reaches one replaces it with smaller rows, each with
  its own finish line, commits that, and only then starts.
- Machine King is never a gate. No job needs his play session to be DONE (see J43).
